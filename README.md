# ⚔️ RPG Tasks & Focus Tracker

Мобильное приложение для прокачки продуктивности и геймификации ежедневных задач. Выполняй таски на максимальную концентрацию с встроенным таймером, получай опыт, повышай уровень и открывай ачивки!

## ✨ Ключевые возможности

* 🎯 **Focus-таймер**: Задачи на максимальную концентрацию. Запускай таймер и фокусируйся на задаче, не отвлекаясь.
* 📈 **RPG-прогрессия**: Завершение задач приносит очки опыта ($XP$). Набирай опыт, чтобы повышать уровень персонажа.
* 🏆 **Система ачивок**: Разблокируй достижения за регулярность, количество выполненных задач и суммарное время фокуса.
* 📅 **Ежедневные трекеры**: Удобный менеджмент задач и привычек на каждый день.
* ⚡ **Быстрое состояние**: Полностью локальное и мгновенное управление данными с помощью **Zustand**.

## 🛠️ Технологический стек

* **Framework:** [React Native](https://reactnative.dev/) / [Expo](https://expo.dev/)
* **State Management:** [Zustand](https://github.com/pmndrs/zustand)
* **Language:** TypeScript
* **UI & Animations:** React Native Reanimated
* **Локализация:** i18n
